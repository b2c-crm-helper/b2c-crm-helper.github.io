# Помощник оператора CRM: установка

Инструкция для операторов: https://zhumabekovmerei.github.io/crm-helper-install/

Скачать установщик для Windows 10/11 (последняя версия):
https://github.com/ZhumabekovMerei/crm-helper-install/releases/latest/download/CRMHelper-Windows.zip

Распакуйте архив («Извлечь все…») и запустите `install.bat`. Права администратора не нужны.
